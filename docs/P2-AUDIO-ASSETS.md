# P2 原创打击音效资产

这批声音给「决战日不落之巅」补上分层的动作、接触和落地反馈。共 14 类、每类 2 个小变体；不含 BGM，不替换真实猫叫，不提取商业游戏音频。本文件只记录声音资产与离线检查，不表示运行时已经接好，也不表示已经发布或完成听感验收。

## 交付与复现

- 28 个 WAV：`assets/audio/p2/<cue>_1.wav`、`<cue>_2.wav`。
- 可复现源码：`scripts/generate_p2_audio.py`。作者来源为本项目的 OpenAI 助手原创程序化合成；输入只有明确的数值参数和固定种子的 xorshift32 噪声，没有外部录音、采样素材库或第三方游戏音频。生成音效不存在外部采样许可依赖；本说明不替项目另行授予许可。
- 逐文件测量、分层配方、种子与 SHA-256：`assets/audio/p2/manifest.json`。
- 分组叠音证明和压力测试：`assets/audio/p2/mix-checks.json`。
- 资产和报告逐字节校验：`assets/audio/p2/SHA256SUMS.txt`。
- 参考环境：Python 3.12.14、NumPy 2.3.5。没有随机时间戳；同一参考环境生成结果逐字节一致。不同体系架构的浮点数学可能有最后一位差异，`--check` 会发现，而不会静默覆盖。

从工程根目录执行：

```sh
python3 scripts/generate_p2_audio.py
python3 scripts/generate_p2_audio.py --check
(cd assets/audio/p2 && sha256sum -c SHA256SUMS.txt)
```

`--check` 只读检查已有交付，不写文件；同时在内存中重做合成、336 项逐文件检查与 5 项混音检查。源码哈希也记录在 manifest；修改源码后应重新生成并复核。

## 声音构成与建议增益

音效由短带限噪声瞬态、非整数频率比的衰减共振、低中频身体感叠加而成。不是一条正弦波的提示音，也不把所有招式简单变调复用。拳击、直拳、重拳、踢击各有不同包络、层数和后续脉冲。没有骨裂、血肉、尖叫等拟伤害素材。

下表的增益是播放器的**线性音量**，不是 dB，也不是在已有衰减后再次相乘。dB 对照和每层完整参数见 manifest。每次事件选一个变体，不同时叠两份，不额外随机变速/变调。

| Cue | 时长，秒（1 / 2） | 建议线性增益 | 设计意图 |
| --- | --- | --- | --- |
| `swing_punch` | .125 / .129 | .12 | 短促衣料与破风，没有命中闷响。 |
| `swing_kick` | .195 / .199 | .14 | 更宽的双层破风，区别于拳。 |
| `hit_light` | .105 / .109 | .20 | 单次干脆的软垫式轻击。 |
| `hit_straight` | .165 / .169 | .22 | 先接触、后跟进的中频身体感，与刺拳节奏不同。 |
| `hit_heavy` | .250 / .254 | .24 | 更厚的低中频闷击、掌击瞬态与短尾音。 |
| `hit_kick` | .215 / .219 | .23 | 宽拍击后有独立的缓冲脉冲。 |
| `block` | .115 / .119 | .18 | 紧短的护具碰击，避免长金属响。 |
| `guard_break` | .270 / .274 | .22 | 三个错开的柔和碰击与衣料释放声。 |
| `jump` | .105 / .109 | .10 | 轻量衣料抬起、足底离地。 |
| `land` | .120 / .124 | .12 | 两次接近的软鞋底接触。 |
| `down_land` | .245 / .249 | .20 | 两段缓冲落地和短舞台共振。 |
| `ko` | .325 / .329 | .22 | 两段下行收束共振，不使用人声或伤害拟音。 |
| `ui_confirm` | .105 / .109 | .12 | 双段轻触木质点击，保持短小。 |
| `heart_emit` | .185 / .189 | .14 | 温暖的空气弹出与上行短脉冲，不替代猫叫。 |

变体 2 使用另一个固定噪声种子、小幅阻尼/频率变化和约 1–2 毫秒的局部错位，总长只增加 4 毫秒。变体间变化小；招式间变化来自不同的配方，不是仅仅换音高。

## 离线验证结果

- 全部为单声道、48 kHz、16-bit PCM，无循环；28 个 WAV 共 491,408 字节，时长 .105–.329 秒。
- 每个文件的采样峰值为 −10.500446 dBFS（0.298522949），低于 −8 dBFS 的目标上限；全片 RMS 为 −30.874 至 −25.839 dBFS。
- 8 倍 FFT 插值峰值估计为 −10.500 至 −9.928 dBFS，仍保留余量。这只是补充数值检查，不是经过认证的 ITU true-peak 表或硬件测量。
- 两端严格为零，使用 1.2 毫秒渐入和最长 18 毫秒渐出；邻近端点平滑且低于阈值，末尾 4 毫秒 RMS 低于 −50 dBFS。PCM 整数和严格为零，没有直流偏移或削波样本。
- 250–4000 Hz 占每个文件总频谱能量至少 60.8%；100 Hz 以下最多 0.0693%。声音设计不依赖超低频。频段比例是手机播放的数值代理，不能证明手机扬声器实听效果。
- 刺拳与直拳不只是音高区别：前者是短单段接触，后者包含 10 毫秒噪声跟进与约 19 毫秒的中频身体脉冲；首个变体波形相关系数为 −0.037737。该数值辅助辨别实现，不代替听感判断。
- 原地重新合成、现有文件比对和 SHA-256 读取检查全部通过。

## 分组叠音预算

以 6 个战斗/动作通道、2 个真实猫叫通道、2 个 UI 通道为上限，主增益不超过 1.0：

| 组 | 最多同时播放 | 每通道线性增益上限 | 每组最坏采样峰值贡献 |
| --- | --- | --- | --- |
| 战斗/动作（包括爱心、KO、落地） | 6 | .24 | .429873047 |
| 真实猫叫 | 2 | .11 | .174842529 |
| UI | 2 | .12 | .071645508 |

所有样本峰值绝对值之和不超过 **.676361084，即 −3.396428 dBFS**。这个边界对任意开始时间、相位、变体都成立，但前提是实际运行时遵守上述数量和音量限制，没有额外 BGM、其他音源、增益提升或超预算效果器。

另外验证了：

1. 人为对齐 10 个声音的最大峰值，并翻转极性制造最坏情况，实测恰为 −3.396428 dBFS。
2. 12 秒、351 个事件的固定密集片段，在遵守分组上限的前提下，峰值为 −17.764325 dBFS，RMS 为 −32.235584 dBFS。这是离线压力片段，不是真实对局录音。
3. 用每个文件的 8 倍 FFT 插值峰值重新求保守叠音估计，为 −3.009026 dBFS；这不是对任意硬件 DAC 的保证。

本批 28 个 `.wav.import` 固定 `compress/mode=0`（无压缩 PCM）、`edit/normalize=false`、`edit/trim=false`、不循环、不强制降采样；Godot 默认生成的 QOA 压缩已在这批新资产上关闭，以免有损重建改变峰值预算。运行时应重新导入后验证实际资源。既有猫叫导入设置未更改，运行时若经过有损压缩，应另验其解码峰值或直接读取原 PCM。不要打开 Godot 导入归一化，否则会破坏这个预算。上述文件峰值故意保留余量；如要整体提高响度，必须先调整并验证实际混音预算，不能只提高播放器音量。动作声应在动作被接受时触发，命中声只在真实接触时触发，格挡与破防不能重复叠成普通命中。静音、暂停、切回菜单和失焦等生命周期必须由运行时统一停声。
