# 固定可视摇杆 HUD 接口（功能 v12 候选）

仅修改 `scripts/hud.gd`；战斗逻辑、键盘输入、移动速度及跳跃数值不变。独立测试由另一worker承担；此文不是验收通过声明。

- 保留 `_direction_pad`、`_direction_actions_at()`、`command(action,pressed)`、触点字典与方向动作名称。
- 基座节点 `FixedJoystickBase`；上层实心圆钮 `JoystickNub`。底座位置固定；按钮直径为side×0.36，最大偏移side×0.32，始终收在基座内。箭头只是辅助视觉，不是小按钮。
- `_joystick_touch_id`：唯一方向触点，-1无触点；第二个底座触点不抢占、不合并、不在首指松开后自动升为owner。鼠标与触摸同样互不抢方向控制；攻击触点仍独立。
- `_joystick_vector`：基座中心到触点，按半径归一化并限长1；`_joystick_actions`：当前离散动作；`_joystick_nub`可直接检查局部中心偏移。
- 径向死区进入0.26、退出0.18；各轴进入±0.38、退出±0.26（基座半径单位）。因此纯轴初次动作实际需达到0.38；斜向需双轴都达到阈值。退出到中心时无方向命令，轻微阈值抖动不重复开关。
- 水平方向边沿先于jump，持续保持上方向不发重复jump；明确离开上方向再进入才有新jump边沿，战斗层已有jump held边沿语义不变。
- 持有owner拖出底座：仍按方向限长，不变成攻击触点。此行为有意替代旧方盘“拖出中立”。释放、cancel、焦点丢失、菜单、暂停、设置/结果覆盖层沿既有清理路径归中。
- 旧测试中“多个方向手指合并”“鼠标加触摸方向合并”“底座外拖动中立”的期望已不适用；不能因旧期望失败退回原方盘语义。
