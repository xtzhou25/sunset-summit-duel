# 三角色有界稳定性检查：六种对阵

## 结论与修改边界
本轮只新增 QA 脚本、结果和本文，未修改玩法、伤害、冷却、AI、动画或模型。没有发现 CD 绕过、护条越界、重复发弹或单边位置优势。现有同一 AI 策略下，七对鱼出现优势信号，应记录而不是直接认定真人对战失衡；没有足够因果证据据此削弱步枪。

## 方法
- 三个不同角色组合，每组 24 个固定种子，每种种子交换左右各打一局，即六种有序对阵各 24 局、共 144 局。每局独立重放一次，所有指标精确一致。
- 左右双方运行同一个未修改的 AI 类。只把公开世界的敌/我槽与弹体归属映射给各自 AI；位置坐标不变，AI 不读对方输入。两条 RNG 流绑定角色而不是左右槽，交换位置时保留。
- 采用原生 Godot 导入模型与生产 signature_emitter，预取每角色两朝向在真实发射时刻的口部/手部/枪口坐标，作为纯规则测试发射位置。没有使用旧粗略 fallback muzzle，避免对远程对阵引入额外误差。坐标详见 JSON。
- 以 60Hz 固定模拟步进测量；局长是模拟秒数，不含双方共用 hitstop 的真实墙钟停顿。不是整场渲染、设备 FPS、声音延迟或人工试玩测试。
- 再做鱼/七的 48 局 RNG 流交换与 48 局双边禁用专属指令诊断，均重复一次。总共 240 个配置局、480 次执行；重复局不是额外独立样本。

## 伤害、防御、冷却证据
伤害是事件申报伤害，可能包含最后一击超出剩余 HP 的部分，不等于有效扣血总额；JSON 同时保留结束 HP。

|---|---:|---:|---:|---:|
|因 / 鱼|84.25 / 88.04|96 / 106|0 / 2|82/108 / 68/96|
|因 / 七|87.63 / 83.46|104 / 108|2 / 0|66/90 / 80/100|
|鱼 / 七|74.92 / 93.13|83 / 99|2 / 2|52/87 / 87/103|

- 生命与护条每步均在合法范围，最低护条可以正常到 0；不能把破防视为越界。
- 冷却每步在 0–4s，全部再施法间隔至少 4s；基础样本最短约 4.033s。
- 每次施法至多发出一枚弹体；发射数小于施法数可由受击打断或回合结束造成，不是缺失计数。
- 已记录各招使用数、双方平均/最低护条、施法/发射/命中数、伤害、结束 HP 和逐局胜负；见 symmetric-matchups.json 与 symmetric-summary.json。
- 基础 1,999,684 次断言、诊断 1,418,272 次断言零失败，大多数为逐帧范围检查，绝非数百万种独立玩法场景。

## 七对鱼的信号与不确定性
基础 48 局：鱼 15 胜、七 33 胜。RNG 流反向分配的额外 48 局：鱼 19 胜、七 27 胜、平 2。合并为七 60 胜、鱼 34 胜、平 2；胜率 62.5%，平局计半分的得分率 63.54%。以原始 24 个种子为簇而非把镜像/重复当独立样本，固定随机 bootstrap 的 95% 得分区间约 51.0%–76.0%。这是特定 AI 策略的小样本诊断，不是玩家总体胜率估计，也未作多重比较校正。

基础样本七的射击命中/发射为 84.5%，鱼的爱心为 59.8%，值得关注。然而双方禁用专属指令后仍是鱼 16、七 32，故不能把胜差简单归因于步枪。此诊断只去掉指令而保留 AI 其他决策，改变了决策机会，且没有额外进行反向 RNG 流版本，不是完美的因果消融。

鱼与七共享 combat_profile1：近战伤害、起手、有效时长、收招和配置距离上限相同；实际肢体判定曲线各自来自模型测量，存在细微差异。AI 固定决策阈值、微小接触差异导致的后续状态与 RNG 消耗分叉、专属轨迹，以及 24 个种子的抽样波动均可能参与结果。当前不能指定某一个机制为唯一原因，也不为追求 50% 强行改参数。

建议：这次稳定性版本保持数值不变。后续若用户实际体验也持续认为鱼对七明显吃亏，再用固定技能/距离条件及配对人工试玩定位，再决定是否调整。无需自动扩大测试或无限监控。
