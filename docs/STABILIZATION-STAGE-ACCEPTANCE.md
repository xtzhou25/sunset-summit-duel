# RC11 后有限稳定化验收

授权：2026-10-25 用户“请继续按计划优化推进游戏”。当前线上功能 v10 / Sites12 不动，新工作目录 v11 仅隔离候选标记，不代表已经发布新功能版本。

## 本轮范围与停点
1. 从持久化 RC11 回读恢复：ZIP及385项payload SHA完全一致。
2. 真实 Godot4.6.3 Compatibility 原生实际场景、相机、灯光、HUD及动画过渡：24个三角色/双朝向场景，完整七步枪双朝向；通过渲染图片目检与状态manifest共同验收。
3. 六组合手机尺寸原生控制回归、KO/打断/重置；明确不是iPhone/Safari真机。
4. 同策略、角色绑定随机流、交换左右的六组合对阵证据及有界因果诊断。只修明确实现缺陷，不根据AI胜率盲改数值。
5. 若无明确缺陷，保留生产源/模型/数值/线上版本，交付QA证据和现存限制，不为发版制造改动；如有明确缺陷，则局部修复、回归、冷备份并发布既有私有站点。

不包含新招式、新角色、联网、商业化、共享权限变化。Vesper不涉及。

## 真实环境
当前原生 GUI 可经云端 Sky 启动 Godot并导入恢复源。执行器CLI没有DISPLAY，与浏览器loopback不同：本地HTTP服务器在云浏览器连接被拒，已停止；线上私有站点在未登录浏览器显示正常登录门，未绕过或改权限。原生运行日志显示Mesa llvmpipe软件OpenGL，音频设备初始化失败退回dummy：本轮不宣称GPU性能或可听音质验收。

原生编辑器自动删除了project.godot内默认stretch disabled配置的显式行；仅等价序列化，验收后恢复原字节，不把它当功能改进。
