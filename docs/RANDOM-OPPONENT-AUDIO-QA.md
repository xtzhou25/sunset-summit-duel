# 功能 v18 / RC19：随机对手与音效选择

## 默认对手
- 默认「对手：随机」，玩家选角后，从其余四位中等概率抽取；不会抽到自己。
- 一场三局两胜对战只抽一次，下一回合和平局重赛均不换对手。「再战」是新对局：随机模式重新抽取，允许合理地连续抽到同一角色；手动模式保持指定对手。
- 按对手按钮可手动指定；若随后选择该角色作为玩家，则回到随机模式。菜单重绘、窗口变化、战斗每帧和暂停不消耗抽签。
- 独立 RandomNumberGenerator，不调用全局 RNG 或 AI 的 RNG。Characters 的确定性 fallback 仅保留为底层无显式参数的模拟/缺失 HUD 快照兜底，用户开赛走单独 match selector。
- 原菜单按鼠标/触摸选择，既有非焦点按钮不新增 Enter 键菜单导航；战斗键盘控制保持。

## 音效
- 保留因的原 CC0 猫叫、拳/踢/格挡/挥空层级、静音与音效/角色声滑杆。
- 新增鱼的轻柔爱心命中、桃的柔和果实发射/命中、哈的预警/下落/落地；七单发声替换为更短、受控的原创合成声。无新背景乐或人声。
- 音效只消费已经发生的模拟事件；蛋糕命中和触地只响一次，格挡/破防优先；起手受击取消不伪造后续落地声。
- 10 个固定声道、事件去重、优先级、限频和暂停清空机制保留。所有既有 GLB、Combat、AI、镜头、舞台脚本字节不变，伤害/冷却/弹道不变。
- 独立音效来源、幅度与同时混音上界见 AUDIO-SELECTION-REFINEMENT.md。

## 验证
- random_opponent_test：202,072 检查，五角色共100,000次固定种子抽样；排除自身、候选完整、频率、重现、手动稳定和 RNG 独立。
- random_opponent_integration_test：301 检查，三视口×五角色实际 viewport 触摸/鼠标、战斗键盘、回合/平局/菜单/重赛/自选冲突。
- 原30个功能套件通过（26 Godot +4 Node）。5个历史 harness 有退出资源警告，记录在 FINAL-SUMMARY.json；不称全部日志无警告。
- 旧音频池74项 +新增音效42项；五角色 hit/block/miss 与蛋糕中断87项，headless 与原生 X11 均通过。图像仅证明原生画面和事件接线，不证明实际扬声器听感。
- 导出 pack 实际加载验证：5种随机角色、20手动配对、22 cues/43 streams/10 voices；导出 PCK 不含测试试听文件。
- 原生稳定性通过：180.004271秒、3,796渲染帧、20配对/20截图、6次暂停和6次焦点通知清理，0失败；音频411次播放、1次受控限频拒绝、并发峰值3/10，无缺失音频或未知cue。确切记录见 qa/native180.json。

## 边界
当前音频驱动 Dummy，未主观试听验收；无真实 iPhone/Safari/WebGL2 实战验收。原生软件渲染不是硬件帧率承诺。测试通知回调不冒充真实 OS 切后台。音频试听示例单独做了可听增益，不是游戏内音量。
