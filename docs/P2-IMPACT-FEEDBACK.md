# P2 分级反馈 / 功能 v8

## 实现
统一单调 event_id 事件分发：挥空只出挥击音，命中、格挡、破防分别响应。接触点是模拟事件中不可变的实际表现坐标，换边/互换攻击后不重算。所有伤害、判定、CD、招式前后摇和 P1 位移保持，唯一命中停顿调校是重拳85→95ms。轻拳55、直拳65、踢75、格挡25ms。

重拳未挡命中或KO触发最大0.3%视口宽、100ms衰减横向微震，固定相机不缩放/旋转，HUD固定；设置可关闭。火花保持局部蓝色格挡/暖色命中，小范围、不全屏闪烁。

原创28个实体冲击/挥击/落地等 PCM 文件，见音效资产与运行时文档。固定6战斗+2角色声+2界面槽，缓存、有限复音、限流、无排队。原喵声及许可不变。音效/角色声可独立调节，默认85%/100%，静音/暂停/后台立即停声，恢复不补播。偏好本地保存。

角色正式名：kind0紫色为因，kind1黄色为鱼。名称/血条/护条/回合点按角色kind绑定，不以左右槽或世界位置猜测。字体包含因/鱼与设置所有生产文案。

## 验收范围
72真实主场景输入矩阵覆盖两角色双朝向所有近战与各自专属技命中/挡/空；另测互相同时命中、倒地着地、KO、暂停/后台/静音/设置/重开、音画去重和10槽长时间有界。P1移动/蹲伏/跳越与既有招式回归独立记录。

原生有声录像由 Godot MovieWriter 固定60Hz捕获实时引擎音画，受控场景明确标注，不拼装离线音轨或冒称自由AI对战。技术音频峰值/混音门槛不等于真人听感验收。云浏览器没有WebGL2，iPhone/Safari真机性能、多指和听感仍未验证；页面内旋转及输入壳保留且独立回归。
