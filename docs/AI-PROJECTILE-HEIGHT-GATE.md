# 已批准的窄范围 AI 改善：先排除物理上无法跳过的弹道

## 范围与基线
前置只读对阵审计并未证明七/鱼存在数值缺陷；本次修改针对其中识别出的共同 AI 策略问题，不是按胜率削弱某角色。仅运行文件 scripts/ai.gd 改动。combat.gd、characters.gd、主场景、模型、攻击伤害/前后摇/CD/轨迹、输入及音效不变。

## 算法
- 仍保留 240ms 延迟公开观察、固定种子、单弹体一次概率选择、同样的防御概率与错误空间。
- 快照追加当时已存在弹体的 y、vx、vy，不读取玩家输入、不访问未发射攻击或当前未成熟的弹体状态。
- 最大可越过高度 = JUMP_VELOCITY²/(2×GRAVITY) + 受击盒下沿0.15m − 保守余量0.03m，当前为1.32714m。速度/重力直接使用 Combat 常量；0.15m对应现有公共受击盒契约，测试中明确固定。
- 利用旧快照位置/公开速度估算到旧目标水平受击盒近边的时间，对下降心形求近边高度，避免把所有高处生成的心形一律当成水平枪线。这个估算没有把延迟和双方未来移动消除，且只排除不可能/无需跳跃的高度，不保证来得及起跳或一定躲过。
- 原“选择跳跃”的随机分支若高度不可行，改为280ms中性停顿。绝不转成必定防住，也不额外重抽随机数。真正的防御分支概率与持续时间不变，空中或已承诺出招不会因此取消动作。
- 泛用移动/进攻分支仍可能跳跃；指标“徒劳跳跃减少”仅指该弹体应对分支，不声称角色从此绝不会在子弹存在时跳起。

## 验证与因果指标
每种弹体384个地面夹具：64种子×双朝向×中心/靠近墙/墙边三个合法布置；另覆盖对应空中、已承诺攻击状态。受控静态公开世界用来隔离决策，不冒充实际移动弹体的闪避成功率。

|威胁|原弹体跳跃选择|新弹体跳跃选择|原/新防御选择|新增中性停顿|
|---|---:|---:|---:|---:|
|高水平喵波|78|0|144 / 144|78|
|高水平枪线|78|0|144 / 144|78|
|预计进入可跳范围的下降心形|78|78|144 / 144|0|

其余随机选择仍按原来的普通决策处理。新高度测试38073断言通过，含旧/新决策对照、延迟前不可读新高度、边界、空中/动作承诺、有限快照和重置。低水平线仍可作为跳跃候选，静止异常速度与低于受击盒的弹体不触发该跳跃分支。

旧回归：实际 main AI18项、P3意图1196项、空间224项、弹体247项全部通过。全部三角色/音频/触控回归与最终导出由发布流程另行核验。本报告不代替这些门槛，也不代替视觉、手机或听感测试。

不以胜率接近50%作为验收；此前六对阵统计属于旧基线，应保留而非覆盖成新版本的真人平衡结论。后续只需确认本次行为修复与回归，不继续做无限制平衡搜索。
