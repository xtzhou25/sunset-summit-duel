## 说明及限制
- 原方形方向盘允许多指方向合并、拖出归中；摇杆明确改为单owner且拖出仍保持方向直到释放，不保留冲突的旧期望。旧hud_test本身仍访问已移除的独立left/right按钮，已停止并保留日志，不记作通过；新原生摇杆测试替代其输入契约。
- GUI使用软件OpenGL，不提供手机帧率证明；无真实iPhone/Safari、本轮浏览器WebGL实战或主观听音验收。
- 最矮横屏摇杆直径68px，方向离散以保持格斗速度，右侧攻击区不变；并非按推杆距离变速。
- 首次CLI未指定可写user目录导致Godot日志目录创建失败并退出；后续明确用workspace内XDG路径运行通过，无权限绕过。
- 原生编辑器移除显式默认stretch=disabled；交付前恢复原字节，不改变布局配置。
