# 七：独立运行时接口验收（最终 v03 资产）

2026-10-25 UTC；Godot 4.6.3 原生 headless，隔离 v10。未修改 gameplay/core、未部署。精确文件哈希见 `exports/qa-v10/qi-independent-qa-hashes.json`。

## 通过范围

- `qi_runtime_contract_test.gd`：312 检查。六个有序不同角色组合及实际姓名/血条颜色；24 个真实 main 循环技能案例覆盖七在两槽、两朝向、命中/防御/高空空间未命中。输入启动技能，非直接注入发射事件；独立导入同一 GLB，读取导出契约与骨骼坐标验证 0.40 秒实际发射口；唯一发射、伤害、冷却及再按无二次发射。两朝向真实重击打断；暂停/恢复/后台清输入、菜单清理；低 HP fixture 由真实重击造成 KO，并验证自动下一回合恢复与角色保持。另有两朝向近身射击案例。
- `qi_choice_input_test.gd`：990 检查。375×614、390×791、568×267、844×337、960×600 实际 InputEventScreenTouch / 鼠标点击新对手按钮与三个选择按钮；显式对手或自选冲突时不同默认对手；实际再战按钮保留组合。另 100 次选择及再战，缓存模型≤3、每个 actor 恰有模型与枪根、枪根恰为两个独立节点、模型保持 child0、音频播放器固定10、菜单清除弹体/反馈/枪。
- `qi_bounds_test.gd`：118 检查，112 个实际加权蒙皮姿态（步枪动作 0–1.10s，每0.02s，两朝向），另测实际可见枪网格；六个窗口尺度、左右场地边界投影均在 HUD 与控制区之间。最小边距23.24px；568×267边距25.45px；375×614边距36.56px。枪显隐区间检查通过。

## 边界及发现

- 上述 bounds 是固定姿态几何夹具，不是浏览器/触屏设备实测，也不是衣物穿模目检。最终服装有限采样目检及已知局部接触由模型专门报告承担。
- 空间 miss 使用 y=8m 的测试夹具，只证明轨迹错开时不会造成伤害，不声称普通跳跃必能躲开步枪。当前普通跳跃最高高度与 hurtbox 下沿不足以完整越过1.548m的枪口射线。
- 近身中心距0.70m两朝向实际会命中：虽枪口在角色前方，仍与防守者 hurtbox 重叠。没有将发射口伪造到身体中心，也不声称近身必空。
- 模型最终 SHA256：4076d5bfbabc683d32c76ffe95fef038ee5ea16bb77ee4738f36761a78fb3f68。
- 日志保留在 `exports/qa-v10/qi-*-final.log`；JSON有数值结果。部分 headless 退出有资源仍引用警告，100次循环的场景节点/缓存/音频池有界断言通过；不将退出警告冒充长期内存曲线验证。
