# P3 攻防节奏审计 / 功能 v9

## 有界修改
仅 scripts/ai.gd 行为变化；combat.gd 与 P2 字节一致，未改伤害、帧时序、速度、命中盒、冷却、蹲伏规则、动画、音效或按钮。AI 新增中距离短退/停步/接近三种意图，选择后保持 170–320ms；已延迟观察到换边时清空旧移动意图并重新判断 120ms，不取消既有出招。重击后的 240ms 重新判断保留。

观察沿用 240ms 公开状态历史，新弹体只在真正发射后进入历史，没有读取输入或未发生施法。每枚新弹体一次概率选择：32% 条件允许时防御，接下来 23% 跳跃，其余继续普通决策；不保证每发完美响应。固定 64 个种子静态弹体夹具中分别 24 次挡、13 次跳、27 次无专项反应。此夹具不等于实战闪避成功率。观察/弹体身份/移动意图在回合重置时清空。

“推力参数”不是最终位移米数：它经过受击速度、衰减和舞台边界；格挡只有该参数 35% 的即时推移。近战距离按实测肢体曲线与上限取小，再计入对方 0.26m 水平受击体积，不能把表中上限当作整个有效期恒定触及距离。

喵波：总动作 1.00s，0.38s 发射。爱心波：总动作 1.05s，0.48s 发射。两者 CD 4s、伤害 12、命中硬直 0.26s、护条消耗 28，弹速 3.6m/s、寿命 1.25s。CD 从接受输入起算，受击打断不退还。弹道差异不改。

所有格挡保留无额外独立 blockstun 的简化规则，只有统一 25ms 命中停顿和推移；不是经典逐招格挡硬直系统。被挡后攻击者仍须完成原收招，防守者可用新输入反击。破防受击增加 170ms 硬直。普通受击保护为受击硬直加 180ms；倒地恢复保留起身保护 350ms。KO 永久倒地直到回合重置，不能计入“无限失控”统计。

轻拳仅允许第一段结束前 120ms 的一次新按下进入第二段，第二段后 190ms 行动锁；其他招式无取消链。重拳/回旋/专属必须松开再按，按住不自动重复。飞踢可以在完整恢复后再次发起，但不绕过起手或收招。大收益近战均至少 280ms 起手与 400ms 收招，没有无代价连续重击。

## 可复现比较与解释
每版 80 个场景：两角色 × 五个脚本策略 × 八个固定种子；每个场景再独立重复一次，比对完整结果。五策略为混合输入、按住轻拳、反复新按重拳、靠墙后退连续发波、跳越/空中方向/飞踢。相同脚本、种子、60Hz 模拟步进；不是人工对战，不是浏览器帧率评测。结果逐局记录距离 p10/中位/p90、近身比例、最长失控、各招次数、局长及胜负，见 exports/qa-p3/rhythm-metrics.json 与 summary.json。

- 全部策略平均近身时间（间距<1m）63.4% → 58.9%，混合输入策略 52.7% → 43.5%。各策略分别下降或近似保持，避免只展示挑选的样本。
- 每局距离中位数的均值 0.889m → 0.927m；平均局长 19.52s → 21.29s。
- 最长连续“不能操控”2.38s → 2.57s。统计仅正生命时 stun>0 或 down=true，包含正常倒地与起身阶段，不是单纯受击硬直，且排除 KO。没有无限连锁，不能把该有限样本当作数学证明所有策略无解。
- 玩家/AI 胜局 41/39 → 33/47。AI 在这组脚本中更强，不声称达成 50% 平衡，也不以脚本胜率冒充用户体验。
- 64 种静态弹体选择夹具证明并非完美反应；额外 32 种子连续方向测试验证意图稳定与延迟换边。

## 验证
P3 规则审计 785037 个断言通过，其中绝大多数是逐帧边界检查，不代表几十万个独立行为场景。新增意图测试 1196 个断言（含 null 弹体、出招承诺不被换边取消）、既有 224 空间规则、247 弹体规则、80 完整随机回合通过。原生真实 main 中两角色自主使用轻/后手/重拳/踢/回旋，18 项测试通过，包括只公开数据的测试世界、重置、私有按键无影响与延迟换边。原生退出仍有既有 ObjectDB/resource 清理告警，未隐瞒为全日志零警告。

P4 另作持续 10 分钟运行与资源回归。没有 WebGL/iPhone/Safari 真机、物理多点触控或用户听感验证；本阶段也没有假称人工试玩。当前仅新增节奏而不扩展高低段、投技、超级槽、联网或付费系统。
