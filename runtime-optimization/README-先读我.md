# 决战日不落之巅 · Windows 体积优化版

基于已确认的功能 v18 / RC19（Sites20）导出；五角色、随机对手、专属音效、开源待机动作、28 位观众与三层滚动舞台保留。没有修改线上网页，也没有替换人物或渲染风格。

## 开始游戏
1. 将整个 ZIP 解压到一个文件夹，不要直接在压缩包里运行。
2. 双击 `SunsetSummitDuel.exe`。`SunsetSummitDuel.pck` 必须与 EXE 放在一起，名称不要改动。
3. 鼠标选择角色；默认随机选择其他四位角色之一，也可指定对手。

离线原生运行，不需要浏览器、联网、安装 Godot 或管理员权限。目标平台：Windows 10/11 64 位（x86_64），显卡需支持 OpenGL 3.3；此版使用 Compatibility 渲染器。

## 操作
- A / D 或左右方向键：移动；向后移动可防御地面正面攻击。
- W / 上方向键 / 空格：跳跃；S / 下方向键：下蹲。
- J：刺拳 / 连拳；K：飞踢；L：重拳；I：回旋踢；O：专属技。
- Esc：暂停 / 继续；F11 或 Alt+Enter：全屏 / 窗口切换。
- 设置中可调音量及动态效果；点击静音控制可静音。
- Alt+F4 或窗口关闭按钮：退出。

桌面版不显示手机摇杆/攻击触摸区，底部显示按键提示与专属技冷却。默认 1280×800，可调整窗口大小；最小 960×600。

## 验证与边界
这是原生 release 版本，不是网页套壳。此版使用从官方 Godot 4.6.3 源码重新编译的体积优化运行时：保留 OpenGL 3 渲染、3D、动画、物理、音频、字体和高级中文排版，关闭本游戏未使用的 Vulkan、Direct3D 12 与 XR 支持。游戏 PCK 与之前版本逐字节一致，没有降低模型、动作或音频质量。具体差异见 SIZE-OPTIMIZATION.md 和 BUILD-PROVENANCE.json。

源文件完整性、资源包和游戏逻辑自动化检查已完成；原版运行时的 Linux 图形检查也已通过，但新编译的 Windows EXE 尚未执行。原版检查记录保留于 BASELINE-BUILD-REPORT.md，不等于新 EXE 的运行验收。

没有可用的 Windows 真机或 Wine 运行环境，因此不宣称已完成 Windows 运行、实际显卡性能、声音听感或系统级快捷键实测。EXE 未代码签名，系统可能提示发行者未知。请保持安全软件开启；若系统拦截，请先核对来源与 SHA256，不要关闭安全保护。

原生运行解除网页容器限制，但本版优先保持当前画面和规则一致，不承诺自动提升画质或帧率。
